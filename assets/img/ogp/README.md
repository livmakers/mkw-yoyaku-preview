# OGP画像 (1200×630)

- `default.png` … サイト共通(未設置。テンプレートから書き出して設置)
- `{campaign_slug}.png` … 企画別(任意)

## テンプレートからの作り方
1. `template.svg` をブラウザで開く(下記)
2. 企画名・期間のテキストを書き換え
3. スクリーンショット or SVG→PNG 変換(1200×630)で書き出し、このフォルダに置く

`template.svg` は生成り地+青海波+朱丸+企画名(Yuji Syuku指定)の構成。
サーバでのPNG自動生成はXserverのGD+日本語フォント設置が前提のため、
初期運用は手動書き出しとする(運用手順書参照)。
